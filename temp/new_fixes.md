## 技术细节

### 曲线绘制状态管理

```javascript
ManimEditor = {
    curvePoints: [],        // 当前正在绘制的点
    isCurveDrawing: false,  // 是否正在绘制曲线
    curvePreviewPoint: null // 鼠标预览点
}
```

### 贝塞尔曲线公式

三次贝塞尔曲线使用Canvas的 `bezierCurveTo(cp1x, cp1y, cp2x, cp2y, x, y)` 方法：
- P0：起点（moveTo）
- P1：第一个控制点（影响起点曲率）
- P2：第二个控制点（影响终点曲率）
- P3：终点
