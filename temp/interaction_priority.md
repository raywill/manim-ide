# 交互优先级设计文档

## 🎯 问题场景

**之前的问题：**
```
场景：画布上有一个大矩形占据整个区域
目标：在矩形上绘制一条直线

旧逻辑：
1. 点击"直线"工具
2. 在矩形上拖动
3. ❌ 结果：矩形被移动，无法绘制直线

原因：点击检测优先于绘制模式
```

## ✅ 新的交互优先级

### 优先级设计（按顺序）

```
点击画布 →

┌─ 优先级1：操作选中的元素 ────────────────┐
│  if (有选中元素) {                        │
│    - 点击控制点？→ 调整/缩放              │
│    - 点击元素本身？→ 移动                 │
│  }                                        │
└──────────────────────────────────────────┘
                ↓ 没有匹配
┌─ 优先级2：绘制模式（关键改进！）─────────┐
│  if (绘制模式) {                          │
│    → 开始绘制新图形                       │
│    → 即使点击在其他图形上也绘制 ✓        │
│  }                                        │
└──────────────────────────────────────────┘
                ↓ 不在绘制模式
┌─ 优先级3：选择模式 ──────────────────────┐
│  if (点击了元素) {                        │
│    → 选中该元素                           │
│  } else {                                 │
│    → 取消选择                             │
│  }                                        │
└──────────────────────────────────────────┘
```

## 📋 详细行为表

### 场景1：绘制模式 + 无选中元素

| 点击位置 | 行为 |
|---------|------|
| 其他图形上 | ✅ 绘制新图形（叠加） |
| 空白处 | ✅ 绘制新图形 |

**关键改进：** 可以在已有图形上叠加新图形！

---

### 场景2：绘制模式 + 有选中元素

| 点击位置 | 行为 |
|---------|------|
| 选中元素的控制点 | ⚙️ 调整/缩放 |
| 选中元素本身 | 🤚 移动 |
| 其他图形上 | ✅ 绘制新图形 |
| 空白处 | ✅ 绘制新图形 |

**理由：** 选中元素的操作优先级最高

---

### 场景3：选择模式 + 无选中元素

| 点击位置 | 行为 |
|---------|------|
| 任意图形 | 👆 选中该图形 |
| 空白处 | ❌ 取消选择 |

---

### 场景4：选择模式 + 有选中元素

| 点击位置 | 行为 |
|---------|------|
| 选中元素的控制点 | ⚙️ 调整/缩放 |
| 选中元素本身 | 🤚 移动 |
| 其他图形 | 👆 选中新图形 |
| 空白处 | ❌ 取消选择 |

## 🎬 使用示例

### 示例1：在大矩形上绘制直线

```
步骤：
1. 绘制一个大矩形（占据整个画布）
2. 点击"直线"工具（进入绘制模式）
3. 在矩形上拖动

结果：
✅ 绘制一条直线（叠加在矩形上）
❌ 不会移动矩形

原理：
绘制模式的优先级 > 点击其他元素
```

### 示例2：调整已选中的图形

```
步骤：
1. 选中矩形（有蓝色边框）
2. 点击"直线"工具（进入绘制模式）
3. 点击矩形本身并拖动

结果：
🤚 移动矩形（因为它是选中的）
❌ 不会绘制直线

原理：
选中元素的操作 > 绘制模式
```

### 示例3：快速绘制多个图形

```
步骤：
1. 绘制矩形A
2. 点击"正方形"工具
3. 在矩形A上拖动
   → ✅ 绘制正方形B（叠加）
4. 再次在矩形A上拖动
   → ✅ 绘制正方形C（叠加）
5. 点击矩形A选中
6. 拖动矩形A
   → 🤚 移动矩形A

原理：
未选中的图形不会阻止绘制
```

## 🔄 与之前的对比

### 旧逻辑（问题）

```
点击画布 →
  ├─ 检查是否点击元素
  │   ├─ 是 → 选中并准备移动 ❌
  │   └─ 否 → 检查绘制模式
  └─ 绘制模式 → 绘制

问题：总是优先检查元素，导致无法在元素上绘制
```

### 新逻辑（正确）

```
点击画布 →
  ├─ 优先级1：选中元素的操作 ✅
  ├─ 优先级2：绘制模式 ✅
  └─ 优先级3：选择/取消选择 ✅

好处：绘制模式优先于选择其他元素
```

## 💡 设计理念

### 理念1：选中元素的掌控权

```
选中 = 告诉系统"我要操作这个元素"
→ 所有对该元素的点击都是操作它
→ 不会被其他模式干扰
```

### 理念2：绘制模式的独立性

```
绘制模式 = "我要创建新图形"
→ 不受底层未选中元素的干扰
→ 可以自由叠加
```

### 理念3：清晰的模式切换

```
要移动底层的矩形：
1. 取消当前工具（ESC或点击工具）
2. 点击矩形选中
3. 拖动移动

或者：
1. 直接点击矩形（自动切换到选择模式）
2. 拖动移动
```

```
设计师的典型工作流：
1. 选工具 → 绘制多个 → 调整位置
2. 选工具 → 绘制多个 → 调整位置
3. ...

现在完全支持这个流程！
```
