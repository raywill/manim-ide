## 🔍 如何诊断问题

### 控制台日志解读

**正常的缩放日志：**
```
检测到缩放手柄: bottomRight, 鼠标=(500, 400), 手柄=(490, 395)
准备缩放: corner=bottomRight
缩放: arrow, 角: bottomRight, Shift: false
[缩放] 调用 arrow.handleScale, fixedPoint= {x: -2, y: 1}
[缩放] 返回newProps= {start: [...], end: [...]}
```

**异常情况：**

1. **如果看到：`未实现 getBounds`**
   → registerShape的bug，已修复
   → 刷新浏览器

2. **如果看到：`getBounds返回null`**
   → plugin.getBounds有bug
   → 检查该插件的getBounds实现

3. **如果看到：`未实现 handleScale`**
   → registerShape未复制该方法
   → 已修复，刷新浏览器

4. **如果图形跳变或不动：**
   → handleScale的返回值有问题
   → 查看返回的newProps是否正确

## 📊 预期行为

### Arrow/Line缩放应该：
```
原始：start=[-2,-1], end=[2,1]
拖动右下角：
  → 固定点：topLeft (Manim坐标)
  → 新的start和end按比例缩放
  → 整个箭头/线段变长或变短
  → 角度可能改变（不按Shift时）
  → 角度不变（按Shift时）
```

```
原始：4个控制点 P0, P1, P2, P3

  → 所有4个点按比例缩放
  → 曲线形状保持
  → 整体变大或变小
```

```
原始：x_length=6, y_length=6
拖动右下角：
  → x_length和y_length改变
  → 刻度更新
  → 中心可能移动
```
