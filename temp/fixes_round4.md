### 2. ✅ 贝塞尔曲线导出优化

**问题：** 导出的Manim代码与编辑器显示不一致

**原因分析：**
- 编辑器使用：`bezierCurveTo(P1, P2, P3)` 从P0开始
- 之前导出：`set_points_smoothly([P0, P1, P2, P3])` 
- Manim的插值方式可能不同

**修复方案：**
- 4个点时使用 `CubicBezier(P0, P1, P2, P3)`
- 参数顺序与Canvas完全一致
- 其他数量的点仍使用 `set_points_smoothly`

**导出代码示例：**
```python
# 之前（可能不一致）：
curve = VMobject(color=PURPLE)
curve.set_points_smoothly([[0, 0, 0], [1, 1, 0], [2, -1, 0], [3, 0, 0]])

# 现在（完全一致）：
curve = CubicBezier([0, 0, 0], [1, 1, 0], [2, -1, 0], [3, 0, 0], color=PURPLE)
```

### 3. ✅ 坐标系小数步长绘制修复

**问题：** 步长为0.5时，刻度值可能是0.5000001或超出范围

**修复内容：**

#### a) 从0开始向两边绘制
```javascript
// 从0向右：0, 0.5, 1.0, 1.5, 2.0...
for (let i = 0; i <= xMax; i += xStep)

// 从0向左：0, -0.5, -1.0, -1.5, -2.0...
for (let i = 0; i >= xMin; i -= xStep)
```

#### b) 浮点数精度处理
```javascript
i = parseFloat((i + xStep).toFixed(10))
// 避免 0.30000000004 这样的浮点误差
```

#### c) 小数位数与步长一致
```javascript
步长0.5 → 显示1位小数：0.5, 1.0, 1.5
步长0.25 → 显示2位小数：0.25, 0.50, 0.75
步长1 → 显示整数：1, 2, 3
```

**测试用例：**
```
步长0.5, 范围[-2, 2]:
  显示：-2.0, -1.5, -1.0, -0.5, 0.5, 1.0, 1.5, 2.0 ✓
  
步长0.1, 范围[-1, 1]:
  显示：-1.0, -0.9, ..., -0.1, 0.1, ..., 0.9, 1.0 ✓
```

### 4. ✅ 属性输入框删除键问题修复

**问题：** 在坐标系属性输入框中按Delete/Backspace，图形被删除

**原因：** 全局键盘事件监听Delete键删除元素，没有区分是否在输入框中

**修复方案：**
```javascript
if (type === 'number') {
    // 输入为空、负号、小数点时，不立即更新
    if (value === '' || value === '-' || value === '.') {
        return;  // 保留输入框状态，不更新图形
    }
    
    value = parseFloat(value);
    if (isNaN(value)) {
        return;  // 无效数字，不更新
    }
}
```

**效果：**
- ✅ 可以删除输入框内容
- ✅ 可以输入负号 `-`
- ✅ 可以输入小数点 `.`
- ✅ 只有输入有效数字才更新图形
- ✅ 不会误删图形
