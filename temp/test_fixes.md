### 5. ✅ 所有形状强制使用拖动绘制

**修改内容：**
- 在 `js/ui.js` 的 `finishDrawing()` 中添加最小拖动距离检查（10像素）
- 在 `updateTempElement()` 中为曲线和坐标系添加拖动逻辑
- 拖动距离小于10像素时不创建元素

**验证方法：**
1. 选择任意形状工具
2. 在画布上点击一下（不拖动）
3. 应该不会创建元素（控制台会提示"拖动距离太小"）
4. 拖动鼠标绘制，释放后才创建元素
5. 拖动的大小应该决定形状的大小

**测试所有形状：**
- 正方形：拖动距离决定边长
- 矩形：拖动的宽高决定矩形尺寸
- 箭头/线段：拖动的起点终点决定箭头方向
- 曲线：拖动生成简单的三点曲线
- 坐标系：拖动距离决定坐标轴长度

## 测试步骤

### 完整测试流程

1. **启动应用**
   ```bash
   python3 -m http.server 8000
   # 访问 http://localhost:8000
   ```

2. **测试场景边界**
   - 观察画布中心是否有灰色虚线框
   - 框内是否有"Manim场景边界"标签

3. **测试拖动绘制**
   - 点击"正方形"按钮
   - 在画布上拖动（确保拖动距离>10像素）
   - 释放鼠标，正方形应该被创建
   - 大小应该与拖动距离相关

4. **测试对象拖动**
   - 单击刚创建的正方形（应该被选中，显示蓝色虚线框）
   - 拖动正方形到新位置
   - 正方形应该跟随鼠标移动

5. **测试属性面板**
   - 双击正方形
   - 右侧属性面板应该滑出
   - 观察画布：正方形不应该变形
   - 修改属性（如颜色）应该实时更新

6. **测试线条选择**
   - 点击"箭头"按钮
   - 拖动绘制一个箭头
   - 单击选中箭头
   - 应该看到蓝色虚线框包围箭头
   - 拖动箭头应该能整体移动

7. **测试曲线**
   - 点击"曲线"按钮
   - 拖动绘制曲线
   - 单击选中曲线
   - 应该看到蓝色虚线框包围所有控制点

8. **测试按钮切换**
   - 点击任意形状按钮（如"矩形"），按钮高亮
   - 再次点击同一按钮，按钮应该取消高亮
   - 此时应该回到选择模式

9. **测试ESC键**
   - 点击任意形状按钮
   - 按ESC键
   - 所有按钮应该取消高亮
   - 属性面板应该关闭
