# FunctionPolar 插件

极坐标函数可视化插件，支持用户输入极坐标表达式 `r = f(theta)` 并在矩形视窗内绘制曲线。

## 特点

- **矩形视窗框架**：透明无背景，(0,0) 点位于视窗中心
- **极坐标函数**：支持输入极坐标表达式（如 `sin(3 * theta)`、`1 + cos(theta)`）
- **轴向缩放**：独立的 X/Y 轴缩放倍数，在相同视窗显示更大范围
- **自动容错**：函数计算失败时自动返回 r=0
- **支持 math.js**：如果页面加载了 math.js，自动使用其强大的表达式解析能力

## 属性

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| x | number | 0 | 视窗中心X坐标 |
| y | number | 0 | 视窗中心Y坐标 |
| width | number | 4 | 视窗宽度（Manim单位） |
| height | number | 4 | 视窗高度（Manim单位） |
| expression | string | `sin(3 * theta)` | 极坐标函数表达式 r=f(θ) |
| theta_max | number | 6.28 (2π) | θ最大值（控制旋转圈数） |
| x_scale | number | 1 | X轴缩放倍数 |
| y_scale | number | 1 | Y轴缩放倍数 |
| color | string | `#e74c3c` | 曲线颜色 |
| stroke_width | number | 2 | 线宽 |
| z_order | number | 0 | 渲染层级 |

## 使用方法

1. **绘制极坐标图形**：
   - 在工具箱选择 `◎` 图标
   - 在画布上拖动创建视窗
   
2. **修改极坐标表达式**：
   - 双击图形打开属性面板
   - 在"极坐标函数 r=f(θ)"输入框中输入表达式
   - 支持的运算符：`+`, `-`, `*`, `/`, `^`, `sin`, `cos`, `tan`, `exp`, `log`, `sqrt`, `abs` 等
   - 变量名：使用 `theta` 表示角度（范围 0 到 2π）

3. **调整角度范围**：
   - **θ最大值**：控制曲线绘制的圈数
     - 2π (≈6.28) - 完整一圈（默认）
     - 4π (≈12.57) - 两圈
     - 10π (≈31.42) - 五圈（适合螺线）
   
4. **调整显示范围**：
   - **X轴缩放**：增大值可在相同视窗显示更宽的 x 范围
   - **Y轴缩放**：增大值可显示更大的 y 值范围

5. **示例表达式**：
   - `sin(3 * theta)` - 三叶玫瑰线（建议 θ_max = 2π）
   - `1 + cos(theta)` - 心形线（建议 θ_max = 2π）
   - `2 + sin(4 * theta)` - 四叶玫瑰线（建议 θ_max = 2π）
   - `theta / (2 * pi)` - 阿基米德螺线（建议 θ_max = 10π 或更大）
   - `exp(theta / 10)` - 对数螺线（建议 θ_max = 10π 或更大）

## 导出到 Manim

插件会生成 `ParametricFunction` 代码，自动：
- 将表达式转换为 Python lambda（`^` → `**`，`sin` → `np.sin` 等）
- 极坐标转直角坐标：`[r*cos(t), r*sin(t), 0]`
- 根据 x_scale 和 y_scale 调整显示范围
- 使用 `shift()` 定位视窗中心

### 示例导出代码

```python
polar_1 = ParametricFunction(
    lambda t: [np.sin(3 * t) * np.cos(t) / 1, 
               np.sin(3 * t) * np.sin(t) / 1, 0], 
    t_range=[0, 2*PI], 
    color=RED
).shift([0.00, 0.00, 0])
```

## 注意事项

- 函数表达式中使用 `theta` 作为角度变量
- theta 自动从 0 到 2π 扫描（完整一圈）
- 如果计算失败（除零、超出范围等），该点自动取 r=0
- hitTest 和 getBounds 基于视窗矩形，不考虑实际曲线形状
- 采样点数固定为 800，确保曲线平滑

## 极坐标常见图形

| 表达式 | 图形名称 |
|--------|----------|
| `1 + cos(theta)` | 心形线 |
| `sin(2 * theta)` | 双叶玫瑰线 |
| `sin(3 * theta)` | 三叶玫瑰线 |
| `sin(n * theta)` | n叶玫瑰线（n为奇数） |
| `sin(2*n * theta)` | 2n叶玫瑰线（n为整数） |
| `theta` | 阿基米德螺线 |
| `exp(theta / 5)` | 对数螺线 |
| `1 / (1 + cos(theta))` | 抛物线（极坐标形式） |
