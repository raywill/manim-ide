# Brace 插件测试指南

## 🚀 快速开始

### 1. 打开应用

在浏览器中打开 `index.html`

### 2. 检查插件是否加载

打开浏览器控制台（F12），应该看到：

```
Registered shape plugin: brace v1.0.0
```

### 3. 检查工具栏

在左侧工具箱中应该看到"大括号"按钮，图标为 { (左大括号)

---

## ✅ 手动测试清单

### 测试1：基本绘制

- [ ] 点击"大括号"按钮

- [ ] 大括号应该在默认方向（向上/向左）

**预期结果**：大括号绘制成功，形状平滑

### 测试2：方向控制

- [ ] 选中刚创建的大括号
- [ ] 打开属性面板
- [ ] 将"方向"改为"右侧（顺时针90°）"

### 测试3：控制点拖动

- [ ] 选中大括号
- [ ] 应该看到3个控制点：两个端点 + 一个中间尖端
- [ ] 拖动端点控制点，应该改变大括号的长度和角度
- [ ] 拖动中间尖端控制点：
  - 向外拖动：增加间距
  - 向内拖动：减少间距
  - 拖过中线：翻转方向

**预期结果**：所有控制点都能正常工作

### 测试4：不同角度

绘制以下几种大括号：

- [ ] **水平大括号**：从左到右拖动
- [ ] **垂直大括号**：从下到上拖动
- [ ] **斜向大括号**：斜着拖动（如45度）

**预期结果**：所有角度的大括号都能正确绘制

---

### 测试5：属性调整

选中大括号，在属性面板中调整：

- [ ] **间距（buff）**：改为 0.1, 0.5, 1.0，观察变化
- [ ] **尖锐度（sharpness）**：改为 1.0, 2.0, 3.0，观察弯曲程度
- [ ] **颜色**：改为红色、蓝色等
- [ ] **线宽**：改为 1, 3, 5

**预期结果**：所有属性都能正确应用

## 🐛 常见问题排查

### 问题1：大括号不显示

**可能原因**：
- 拖动距离太短
- 颜色与背景相同

**解决方案**：
- 拖动更长的距离
- 检查颜色设置

---

### 问题2：大括号形状不平滑

**可能原因**：
- 浏览器不支持贝塞尔曲线
- Canvas 渲染问题

**解决方案**：
- 使用现代浏览器（Chrome, Firefox, Edge）
- 刷新页面

---

### 问题3：控制点拖动不工作

**可能原因**：
- 没有选中大括号
- 鼠标位置不准确

**解决方案**：
- 确保大括号被选中（有蓝色边框）
- 精确点击控制点中心

---

### 问题4：导出代码格式错误

**可能原因**：
- 插件版本不匹配
- 坐标值异常

**解决方案**：
- 检查控制台是否有错误
- 重新绘制大括号

---

## 📊 性能测试

### 测试大量大括号

```javascript
// 创建100个大括号测试性能
for (let i = 0; i < 100; i++) {
    const brace = ManimEditor.shapeRegistry.brace.createDefault(
        Math.random() * 10 - 5,
        Math.random() * 10 - 5
    );
    brace.props.point2 = [
        brace.props.point1[0] + Math.random() * 2,
        brace.props.point1[1] + Math.random() * 2,
        0
    ];
    addElement(brace);
}

console.log('创建了100个大括号');
```

**预期结果**：
- 渲染流畅（60fps）
- 交互响应快速
- 内存占用合理
