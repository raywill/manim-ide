# Triangle 插件

三角形图形插件。

## 特点

- **点击式绘制**：点击3次放置3个顶点
- **可编辑顶点**：每个顶点都可拖动调整
- **等比例缩放**：保持三角形形状

## 绘制方法

1. 点击"三角形"工具
2. 点击放置第一个顶点（P0）
3. 点击放置第二个顶点（P1）
4. 点击放置第三个顶点（P2）
5. 自动完成

## 编辑

- **移动**：拖动三角形整体移动
- **缩放**：拖动四角手柄，等比例缩放
- **调整顶点**：选中后拖动任意顶点（绿色圆点）

## Manim导出

```python

```
