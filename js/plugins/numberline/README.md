# NumberLine 插件

一维数轴插件，用于在 Manim IDE 中创建和编辑数轴。

## 功能特点

- **拖动绘制**：通过拖动鼠标创建数轴
- **箭头末端**：数轴末端自动添加箭头，表示方向
- **可配置范围**：支持设置最小值（min）、最大值（max）和步长（step）
- **自动刻度**：根据步长自动生成刻度线
- **数字标签**：可选择是否显示刻度数字
- **灵活定位**：支持任意角度的数轴

## 属性说明

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `start` | Array | `[0, 0, 0]` | 数轴起点坐标 |
| `end` | Array | `[0, 0, 0]` | 数轴终点坐标 |
| `min` | Number | `0` | 数轴最小值 |
| `max` | Number | `10` | 数轴最大值 |
| `step` | Number | `1` | 刻度步长 |
| `color` | String | `#2c3e50` | 数轴颜色 |
| `stroke_width` | Number | `2` | 线条宽度 |
| `tick_size` | Number | `0.2` | 刻度线大小 |
| `include_numbers` | Boolean | `true` | 是否显示数字标签 |
| `z_order` | Number | `0` | Z轴顺序 |

## 使用方法

1. 在工具栏中选择"数轴"工具（图标：━）
2. 在画布上拖动鼠标创建数轴
3. 在属性面板中调整 min、max、step 等参数
4. 可以通过拖动端点调整数轴长度和方向

## Manim 代码生成

插件会生成如下格式的 Manim 代码：

```python
numberline_1 = NumberLine(
    x_range=[0, 10, 1],
    length=5,
    color=DARK_GRAY,
    include_tip=True
).move_to([0, 0, 0])
```

## 注意事项

- 数轴的长度由起点和终点的距离决定
- 数轴末端会自动添加箭头，表示正方向
- 刻度数量由 `(max - min) / step` 计算得出
- 如果数轴不是水平的，会自动添加旋转变换
- 步长必须大于 0，且 max 必须大于 min
